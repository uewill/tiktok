# StepFlow (Flutter) Final

StepFlow 是一个面向跑者的智能步频节拍器，围绕「步频引导 + 训练闭环 + 跑步场景可用性」实现。

## 功能完成情况

### 1. 智能节拍与训练流程
- 快速开始 / 暂停 / 结束并保存训练。
- 目标步频 30~250 SPM（1 SPM 步进）。
- 训练模式：日常 / 节奏跑 / 间歇 / 比赛。
- 配速推荐步频：输入配速（分/秒）给出建议步频。
- 动态自适应：偏差 ≥ 5 SPM 自动微调。
- 坡度自适应：上坡降步频、下坡提步频（模拟坡度输入）。

### 2. 多模式反馈
- 音频节拍：系统 click 节拍。
- 振动节拍：按节拍触觉反馈。
- 语音计数：1-2 节拍引导。

### 3. 实时步频检测
- 使用手机加速度计实时计算步频（峰值检测 + 时间窗换算）。
- 传感器不可用时自动回退到模拟补偿，确保训练流程不中断。

### 4. 数据闭环与趋势
- 每次训练保存：目标步频、平均步频、稳定性（标准差）、达标率、时长。
- 历史记录页查看训练列表。
- 周均 / 月均步频趋势统计。
- 支持清空训练记录。

### 5. 后台与运行稳定性（应用层）
- 支持锁屏保活开关（`wakelock_plus`），减少熄屏打断训练。
- 本地持久化存储（`shared_preferences`），重启后保留历史训练数据。

## 关键实现模块
- `lib/services/cadence_detector.dart`：传感器步频检测。
- `lib/services/feedback_engine.dart`：音频/振动/语音反馈调度。
- `lib/services/background_runtime.dart`：锁屏保活控制。
- `lib/services/session_repository.dart`：训练记录持久化与趋势聚合。
- `lib/services/metronome_controller.dart`：核心训练状态机与策略控制。

## 平台说明
本项目为 Flutter 跨平台实现，面向 Android / iOS。
